# Toy Store KPI Report

Power BI project analyzing toy store sales performance using data cleaning, data modeling, DAX calculations, and interactive visualizations.

## Objective
Analyze sales, revenue, profit, product performance, store performance, and trends over time.

## Tools
- Power BI
- Power Query
- DAX

## Skills used
- Data cleaning
- Data type validation
- Star schema modeling
- Table relationships
- Calculated columns
- DAX
- KPI analysis
- Dashboard design

## Data model
The project uses a star schema with:
- Sales as the fact table
- Products as a dimension table
- Stores as a dimension table
- Calendar as a dimension table

## Analysis performed
- Revenue and profit analysis
- Product performance
- Store performance
- Sales trends by month and week
- KPI tracking
